# Security

Echo stores student names, roll numbers and attendance, so please report
security problems privately instead of opening a public issue.

Use GitHub's **Security → Report a vulnerability** on this repository.
Include the page or file affected, the steps to reproduce, and what an attacker could do.

Never post real student data, passwords, reset links or tokens in an issue or pull request.
If you find a secret that was committed by mistake, report it the same way so it can be rotated.
